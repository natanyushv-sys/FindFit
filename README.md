# FindFit — אבטיפוס

## הפעלה
1. חלץ את קובץ ה-ZIP.
2. פתח את `index.html` בדפדפן.
3. מסך הניהול נמצא בקובץ `admin.html`.

## מה קיים
- דף בית רספונסיבי בעברית.
- קטגוריות, חיפוש דמה, מצב כהה.
- מסך ניהול בעיצוב ראשוני.

## חשוב — אבטחה
מסך `admin.html` הוא כרגע תצוגת עיצוב בלבד. אין עדיין התחברות אמיתית, משתמשים, שרת או מסד נתונים. שדות ההתחברות מושבתים בכוונה. אין להזין סיסמה אמיתית.
כדי להפעיל ניהול מאובטח צריך לחבר שירות אימות בצד השרת ומסד נתונים, להגדיר הרשאות מנהל, ורק אז לאפשר פעולות ניהול. סיסמה שמוטמעת בקובץ HTML או JavaScript אינה מאובטחת.

## מגבלות נוכחיות
אין עדיין חיבור לחנויות, מחירים, מלאי, מעקב מחירים, התראות או AI. אין עדיין פרסום ציבורי.
